AULA 1

Nesta aula vamos criar a pasta principal do Walker CRM e entrar nela pelo terminal.

Terminal

cd walker-crm
AULA 2

Terminal

Terminal

Terminal

AULA 9

O que vai dentro de cada arquivo?

Agora vamos entender cada arquivo da estrutura.

  • server.js → servidor Node.js + Express
  • package.json → configuração do projeto
  • banco.json → dados iniciais
  • package-lock.json → gerado pelo npm
  • node_modules/ → bibliotecas instaladas
  • public/index.html → página
  • public/style.css → aparência
  • public/app.js → JavaScript do site
AULA 10

server.js

O server.js será responsável por iniciar o servidor do Walker CRM.

server.js 
const express = require('express');

const app = express();

const PORT = 3000;

app.use(
  express.json()
);

app.use(
  express.static('public')
);

app.listen(PORT, () => {

  console.log(
    `Walker CRM rodando na porta ${PORT}`
  );

});
AULA 11

package.json

O package.json guarda as configurações do projeto Node.js.

package.json 
{
  "name": "walker-crm",
  "version": "1.0.0",
  "description": "Walker CRM",
  "main": "server.js",

  "scripts": {
    "start": "node server.js"
  },

  "dependencies": {
    "express": "^5.1.0"
  }
}
